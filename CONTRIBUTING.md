# Как пополнить справочник

Можно предложить запись через [форму заявки](https://github.com/x0rif0r/AppDock/issues/new?template=app.yml) или Pull Request. Владелец проекта проверяет источники и принимает изменения; автоматического добавления неподтверждённых банковских приложений нет.

## Что прислать

- Название в App Store и отдельные альтернативные названия.
- Точный числовой App Store ID и историческую ссылку App Store.
- Bundle ID, только если он установлен из надёжных метаданных; иначе `null`.
- Банк/сервис и ссылки на подтверждения связи с ним. Предпочтительны официальный сайт, сообщение банка и архив его страницы.
- Даты публикации/удаления, если подтверждены источником. Не переносите дату первого выпуска другого приложения на банковский вариант.

Не публикуйте IPA, пароли, коды 2FA, токены, Apple ID, историю покупок, номера устройств и личные журналы. Для доказательства метаданных перепишите только ID/название/Bundle ID/издателя/версию — полный iTunesMetadata.plist содержит личные поля.

## Pull Request

1. Добавьте или исправьте запись в `catalog/apps.json`. Один App Store ID — одна запись; несколько выпусков с одинаковым названием могут иметь разные ID.
2. `verification`: `reported` (сообщается источником), `metadata_only` (сверены метаданные, но официальная связь не доказана), `confirmed` (есть первичное подтверждение). Последний статус требует ссылки на первичный источник.
3. `distribution`: `unknown`, `listed` или `delisted`. Это публичная доступность, а не наличие лицензии у конкретного пользователя.
4. Укажите `checkedOn` и пояснения `notes`. Неизвестные значения не придумывайте.
5. Выполните `python3 scripts/validate_catalog.py`. Таблица `catalog/README.md` — обзор; JSON является основным источником данных.

Автоматическая проверка проверяет формат, уникальность и ссылки, но не устанавливает подлинность приложения. Даже успешная загрузка через Apple не доказывает связь с банком. Удалённое приложение может скачиваться по прежней лицензии или быть полностью недоступным — результат зависит от аккаунта.

## Обновления AppDock

Справочник опубликован отдельно от исполняемого кода. В текущей версии AppDock его автоматическая загрузка ещё не подключена. До интеграции ID можно использовать в «Скачать через ipatool». Неизвестную запись следует показывать как кандидата, а результаты проверки аккаунта сохранять только локально.
