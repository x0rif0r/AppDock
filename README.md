# AppDock

**Личная библиотека приложений для iPhone и iPad на Mac.**

AppDock объединяет историю покупок ваших Apple ID, загрузку IPA через ipatool, локальное или NAS-хранилище и очередь установки по USB. Выберите аккаунт, найдите приложение с иконкой, сохраните его и установите на выбранное устройство.

[Скачать релиз](https://github.com/x0rif0r/AppDock/releases) · [Сообщить об ошибке](https://github.com/x0rif0r/AppDock/issues) · [MIT](LICENSE)

Автор: **x0rif0r**. Версия 2.0 — предварительный релиз для **Apple Silicon и macOS 14+**.

## Возможности

- Каталог истории App Store с иконками, поиском и переключением собственных аккаунтов.
- Вход с паролем и отдельным запросом 2FA в интерфейсе Mac.
- Сохранённые IPA отмечены серым; аккаунт лицензии виден в карточке версии.
- Группы приложений, варианты, версии, App Store ID и Bundle ID.
- Категории и пользовательские пресеты для быстрой настройки устройств.
- Очередь скачиваний и установки, пауза, порядок задач, проценты и оценка времени.
- Local и NAS, локальный кэш для работы с сохранёнными файлами без NAS.
- Выбор USB-устройства, модель, iOS, доступные сведения и история установки.
- Получение обоев по USB на поддерживаемых устройствах или выбор картинки вручную.

## Установка

1. Скачайте `AppDock-2.0-macOS-arm64.pkg` из [Releases](https://github.com/x0rif0r/AppDock/releases). Установщик размещает **AppDock.app в /Applications**, без фонового сервиса и скриптов установки зависимостей.
2. Установите внешние инструменты через [Homebrew](https://brew.sh):

   ```sh
   brew install ipatool libimobiledevice ideviceinstaller
   ```

3. Убедитесь, что ваша сборка ipatool поддерживает историю покупок:

   ```sh
   ipatool list-purchases --help
   ```

   При отсутствии команды каталог истории не заработает. Обновите ipatool; наличие команды зависит от установленной сборки.

4. Откройте AppDock из «Программы». Пакет не подписан Developer ID и не нотарифицирован Apple; приложение имеет ad hoc подпись. macOS может потребовать ручного разрешения запуска в системных настройках. Не отключайте Gatekeeper глобально.

Внешние инструменты и сторонние IPA в релиз не включены. Intel Mac в этой сборке не поддерживается.

## Первый запуск

### Apple ID и каталог

Откройте **Мои приложения App Store → Другой аккаунт**, введите свой Apple ID и пароль, затем код 2FA при запросе. Используйте аккаунт **«Медиаматериалы и покупки»**: он может отличаться от iCloud. AppDock не меняет системный аккаунт iCloud.

История загружается по страницам и кэшируется отдельно для каждого аккаунта. Сохранённые IPA, отсутствующие в ответе Apple, могут дополнить каталог с отдельной отметкой «Сохранённый IPA». Сохранённую историю другого аккаунта можно просматривать; для загрузки нужен вход в него. Переключение аккаунтов блокируется при выполнении задач и непустой очереди.

Найдите приложение, выберите категорию и нажмите **Скачать** или добавьте несколько приложений в очередь. Уже сохранённые IPA того же аккаунта отмечены серым. Обновление существующего файла доступно через меню версии в библиотеке. При замене предыдущий IPA сохраняется в резервной копии.

### Local и NAS

В **Хранилище** выберите Local или NAS и папку. Для NAS сначала подключите сетевой ресурс через Finder, например по SMB. Загрузка выполняется на Mac и сохраняется в выбранную папку; удалённого серверного режима нет.

Режимы запоминают разные папки. Выбор новой папки не переносит прежнюю библиотеку автоматически. Перед установкой IPA копируется в локальный кэш и проверяется. Заранее сохранённые копии доступны при отключении NAS.

### Установка по USB

1. Подключите iPhone, разблокируйте его и подтвердите доверие Mac.
2. Выберите устройство и нужные приложения или пресет.
3. Нажмите **Установить на iPhone**. Устройство закрепляется за задачей.
4. Следите за очередью. Пауза действует после текущей операции; очередь хранится в текущем сеансе.

История установки сохраняется по устройствам. Более новые версии на iPhone пропускаются. Оценка оставшегося времени приблизительная; после передачи файла ещё выполняются проверки.

## Лицензии Apple и ограничения

История покупок не гарантирует возможность повторного скачивания удалённого приложения. Apple может отказать в выдаче лицензии или файла. AppDock не выполняет покупки автоматически, не снимает DRM, не переподписывает IPA и не переносит лицензии между Apple ID.

На iPhone приложение может запросить аккаунт, которому принадлежит его лицензия. Этот аккаунт показан в карточке версии, если он присутствует в метаданных IPA. Оплата приложения одним аккаунтом не даёт другому аккаунту право на его бесплатную активацию.

Проверки CRC, SHA-256, ID и Bundle ID выявляют повреждения и несоответствия, но не доказывают подлинность банковского приложения. Успешная установка также не гарантирует запуск, работу сервиса или совместимость с конкретной iOS. Иконки берутся из пользовательских IPA либо проверенного ответа Apple; при отсутствии изображения используется заглушка.

## Данные и безопасность

- Пароль и код 2FA передаются локальному помощнику через stdin/PTY, не через аргументы процесса. AppDock не записывает их в файлы и журналы.
- Авторизованную сессию хранит ipatool в macOS Keychain. Сессия одна текущая; AppDock не создаёт независимые токены для всех аккаунтов.
- Email аккаунтов, история покупок, сведения устройств, обои и кэш сохраняются **локально** в `~/Library/Application Support/IPAOrganizer`. Путь сохранён для совместимости с ранними версиями.
- IPA и метаданные библиотеки находятся в выбранной папке Local/NAS. Метаданные могут содержать Apple ID владельца лицензии. Настройте доступ к своей сетевой папке соответственно.
- Для работы используются сервисы Apple, загрузки App Store и отдельные внешние CLI. Собственного сервера AppDock нет.
- Репозиторий и релиз не содержат пользовательских IPA, аккаунтов, истории, отчётов устройств, обоев или токенов.

## Частые вопросы

| Ситуация | Что проверить |
| --- | --- |
| `license is required` / приложение недоступно | Правильный Apple ID и прежнюю покупку. Удаление со стороны Apple может исключить повторную загрузку. |
| iPhone просит аккаунт покупки | Посмотрите Apple ID в карточке версии IPA. Лицензия не переносится на другой аккаунт. |
| Нет подключённого устройства | Кабель, разблокировку, доверие Mac и установку libimobiledevice. |
| Нет истории покупок | Поддержку `list-purchases` в установленном ipatool и действующую авторизацию. |
| NAS отключён | Подключите ресурс заново или используйте заранее сохранённый локальный кэш. |
| Не удалось получить обои | Функция зависит от iOS; выберите картинку вручную. |

В отчёт об ошибке добавляйте версию AppDock, macOS и описание шагов. **Не прикладывайте пароль, 2FA, токены, IPA и необработанные личные журналы.**

## Сборка из исходников

Нужны Apple Silicon Mac, macOS 14+ и Xcode Command Line Tools.

```sh
git clone https://github.com/x0rif0r/AppDock.git
cd AppDock
zsh build.sh
open build/AppDock.app
```

Сборка использует SwiftUI/AppKit и два собственных C-помощника. Зависимости CLI устанавливаются отдельно. Установочный пакет можно воспроизвести:

```sh
zsh scripts/package.sh
```

Результат — `dist/`; контрольная сумма публикуется рядом с установщиком. Проверка скачанного пакета:

```sh
shasum -a 256 AppDock-2.0-macOS-arm64.pkg
```

## Проверки и статус

```sh
python3 -m unittest discover -s Tests -v
```

Тесты проверяют транспорт входа на тестовой CLI: 2FA, отказ, отмену и отсутствие секретов в публичном выводе/argv. Реальная история проверена на существующей авторизации; новый вход с 2FA требует пользовательского ввода. Интерфейс проверен вручную. Получение обоев испытано на подключённом iPhone; работа NAS требует проверки с конкретным хранилищем. Полная матрица устройств и версий iOS ещё не пройдена — релиз публикуется как предварительный.
