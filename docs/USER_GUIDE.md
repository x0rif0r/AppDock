# Как пользоваться AppDock

[Скачать AppDock](https://github.com/x0rif0r/AppDock/releases) · [Главная страница](../README.md) · [Каталог ID](../catalog/README.md)

Инструкция для AppDock 2.1.2, Apple Silicon, macOS 14 и новее. AppDock сохраняет IPA из App Store по лицензиям ваших аккаунтов и устанавливает сохранённые файлы по USB. Он не извлекает исполняемый IPA из установленного приложения на iPhone.

## 1. Установить приложение и инструменты

1. Скачайте `AppDock-2.1.2-macOS-arm64.pkg` и `SHA256SUMS.txt` со страницы релиза.
2. В папке с обоими файлами проверьте пакет: `shasum -a 256 -c SHA256SUMS.txt`.
3. Запустите установщик. Он размещает AppDock в `/Applications`; пользовательская библиотека хранится отдельно.
4. Установите внешние инструменты:

   ```sh
   brew install ipatool libimobiledevice ideviceinstaller
   ipatool list-purchases --help
   ```

5. Откройте AppDock из «Программы». Сборка имеет ad hoc подпись; установщик не подписан Developer ID и не нотарифицирован. Если macOS блокирует запуск, используйте предусмотренное macOS разрешение для конкретного приложения; не отключайте защиту глобально.

Обновление AppDock: закройте его после завершения очереди и установите новый пакет. IPA, настройки и история хранятся отдельно от приложения. Очередь задач существует только в текущем сеансе — завершите её перед закрытием.

## 2. Выбрать Local или NAS

Откройте **Хранилище**, выберите режим и папку библиотеки. Local и NAS запоминают отдельные пути. Для NAS сначала подключите ресурс в Finder, например через SMB, затем укажите папку на нём.

Выбор другой папки переключает библиотеку, но не переносит файлы. IPA скачивается на Mac, проверяется и добавляется в выбранную папку. Перед установкой файл готовится в локальном кэше. При недоступном NAS используйте заранее сохранённые локальные копии. Работу конкретного NAS проверьте отдельно.

## 3. Войти в нужный Apple ID

Откройте **Мои приложения App Store → Другой аккаунт…**. Введите аккаунт из раздела **«Медиаматериалы и покупки»** на iPhone, пароль и код 2FA, если ipatool его запросит. Аккаунт покупок может отличаться от аккаунта iCloud.

Пароль и код вводятся в окне AppDock и передаются локальному ipatool; AppDock их не сохраняет. Авторизованную сессию хранит ipatool в macOS Keychain.

Запрос кода означает, что ipatool ждёт 2FA. Он не подтверждает доставку уведомления или SMS. Если код не пришёл, используйте код с доверенного устройства Apple или отмените вход. **Отмена не подключает новый аккаунт.**

Проверяйте строку **«Активен»** или **«Сессия подтверждена»**. Выбранная сохранённая история другого аккаунта — это кэш, а не авторизация для скачивания. У ipatool одна активная сессия. При выборе неактивного аккаунта потребуется вход; автоматического незаметного переключения всех сессий нет.

| Действие | Результат |
| --- | --- |
| Выбрать сохранённый аккаунт | Открывается его сохранённая история; при необходимости предлагается вход. |
| Выйти | Завершается активная сессия; аккаунт остаётся в списке. |
| Убрать аккаунт из списка | Неактивный аккаунт исчезает из переключателя; IPA и кэш истории сохраняются. Повторный вход вернёт его. |
| Обновить | История активного аккаунта запрашивается у Apple. |

Переключение и выход блокируются во время задач и при непустой очереди. Дождитесь завершения или уберите ожидающие задачи.

## 4. Найти и сохранить приложения старого iPhone

1. Подключите старый iPhone по USB, разблокируйте и подтвердите доверие Mac.
2. Откройте **Устройства и история**, затем нужную карточку и **Сохранить с iPhone**.
3. Нажмите **Прочитать по USB**. Проверьте имя устройства, модель и iOS.
4. Выберите нужный аккаунт покупок и убедитесь, что его сессия подтверждена.
5. Найдите приложение по названию или Bundle ID. Опция **Только найденные ID** скрывает приложения без точного сопоставления; выключите её, чтобы увидеть весь прочитанный список.
6. Отметьте нужные приложения и нажмите **Скачать в очередь**.

AppDock сопоставляет точные Bundle ID с историей выбранного аккаунта, вашей библиотекой и встроенным справочником. Числовой ItemID учитывается, если телефон его отдаёт. Неоднозначные ID не выбираются автоматически. Название банковского приложения на телефоне может отличаться от названия в App Store.

**Серое приложение с пометкой «IPA сохранён» уже есть в текущей библиотеке или доступном кэше.** Повторная загрузка отключена. Если нужна замена или обновление, используйте действия версии в библиотеке и проверьте владельца лицензии.

История покупок Apple может не показывать отдельные удалённые приложения. Поэтому отсутствие в истории не означает, что IPA точно недоступен. Известный ID из справочника или метаданных помогает попробовать загрузку; окончательный ответ даёт Apple.

**Проверить App Store** проверяет публичную витрину RU. Статус «Нет в витрине RU» не означает отсутствие лицензии и не доказывает удаление во всех странах. Встроенный справочник обновляется вместе со сборкой, а не непрерывно с GitHub.

## 5. Следить за очередью

Откройте **Очередь задач**. Скачивания и установки выполняются последовательно. За скачиванием закреплён Apple ID, за установкой — выбранное устройство.

- Процент скачивания отражает передачу IPA. После 100% ещё выполняются проверка и добавление в архив.
- Оценка времени приблизительная и меняется со скоростью передачи.
- Пауза действует после текущей операции. Ожидающие задачи можно удалить или изменить их порядок.
- При включённом **Остановить при ошибке** очередь ставится на паузу. После устранения причины нажмите **Продолжить**. Завершившуюся ошибкой загрузку нужно добавить заново.
- У установки отображается число завершённых приложений. Точное время одной установки может быть неизвестно.

## 6. Передать сохранённый набор на iPhone

1. В разделе **Сохранить с iPhone** установите нужный поиск. Кнопка **К установке · N сохранённых** показывает количество сохранённых IPA текущего списка.
2. Нажмите её: AppDock выберет эти IPA и сохранит набор с именем устройства и поисковым запросом. Поиск одного приложения выбирает только его, а не остальные IPA телефона.
3. Подключите целевой iPhone, разблокируйте и подтвердите доверие. Выберите его в главном окне — проверьте имя, модель и iOS.
4. Проверьте выбранные IPA и Apple ID лицензии. Выберите только одну версию каждого Bundle ID.
5. Нажмите **Установить на iPhone**. Устройство закрепляется за задачей.
6. После завершения откройте **История → История установок**. Успешная запись означает, что требуемая версия повторно прочитана с устройства после установки.
7. Откройте приложение на самом iPhone: успешная установка ещё не подтверждает запуск или работу банковского сервиса.

По умолчанию такая же или более новая версия на телефоне пропускается. Для повторной передачи той же версии включите **Переустановить такую же версию** перед добавлением задачи. Предварительное удаление приложения не требуется. Более новая версия на телефоне всегда пропускается. После проверки отключите эту опцию, если повторная установка не нужна.

Наборы также можно создавать в главном окне: выберите IPA, введите название и нажмите **Сохранить**. Все приложения библиотеки доступны в разделе **Все**.

## 7. Если удалённое приложение не скачивается

| Результат | Что делать |
| --- | --- |
| `license is required` | Проверьте активный Apple ID. Попробуйте другой собственный аккаунт, который ранее получал приложение. Наличие приложения на телефоне не доказывает лицензию выбранного аккаунта. |
| `item is temporarily unavailable` | Apple не выдала файл; даже прежняя лицензия не гарантирует повторную загрузку. Сохраните уже полученный подлинный IPA, если он у вас есть. |
| Передача прервалась | Это не доказательство отсутствия лицензии. Проверьте сеть, возобновите очередь и повторно добавьте загрузку. |
| На телефоне запрос другого Apple ID | Сверьте владельца лицензии в карточке IPA; установка не переносит лицензию между аккаунтами. |
| ID не определён | Проверьте метаданные и справочник. Не подставляйте ID другого приложения по похожему названию. |

AppDock не выполняет покупки автоматически, не обходит DRM и не переподписывает приложения. Для банковских вариантов проверяйте связь с банком по официальным источникам: успешная загрузка сама по себе не доказывает подлинность.

Для отсутствующего в витрине приложения с известным ID, которого нет в справочнике, доступна кнопка **Предложить в каталог…**. Она открывает черновик GitHub-заявки. Добавьте источник и отправьте самостоятельно; аккаунт, UDID и серийный номер в черновик не включаются. Правила — в [CONTRIBUTING.md](../CONTRIBUTING.md).

## 8. Карточки устройств

AppDock сохраняет сведения и историю устройства. **Забыть устройство** удаляет его карточку и историю после подтверждения; телефон и IPA не затрагиваются. Подключённое устройство снова появится при сканировании.

Для изображения настоящего экрана блокировки с часами и виджетами сделайте снимок на iPhone, передайте на Mac и выберите **Экран блокировки → Импортировать снимок**. Это сохранённое изображение, а не живой экран. USB-снимок требует доступной службы screenshotr; её работа зависит от настройки устройства. Обои по USB — отдельное изображение без часов и виджетов.

Пользователь подтвердил запуск без запроса другого Apple ID. Проверены серое состояние сохранённого IPA и выбор ровно одного приложения после поиска.

Отдельная попытка Filter T вернула отказ Apple в лицензии. Это результат конкретного аккаунта, а не общий статус приложения для всех пользователей. Перенос на другой чистый iPhone, все версии iOS и конкретные NAS отдельно не испытаны. Релиз остаётся предварительным.
